# Animeghaa Production House website v03

Bright, professional static portfolio. Animation leads the homepage. Dedicated pages organise animation, 3D modelling, graphic design and illustration. The updated cinematic reel is used on Home and Animation.

## GitHub Pages

Extract the ZIP and upload the CONTENTS of this folder to your repository root, including index.html, styles.css, script.js, portfolio-data.js, the other HTML pages and assets/. Keep .nojekyll if using Git. In repository Settings > Pages select your branch and the root folder. No build command is needed. All links and asset paths are relative, so project repositories work too.

## Netlify

Drag this folder into Netlify's manual deploy area. No build command is needed.

## Editing

Gallery content is in portfolio-data.js. Page cards are in their corresponding HTML files. The six supplied medical device renders are one modelling project. Existing illustration applications have been separated from graphic design projects. Project titles for the three new illustrations are descriptive labels and can be renamed.

The Gmail link opens a prefilled project enquiry in Gmail Web. Visitors sign in and send the message themselves. The phone link opens a supported device dialler.
